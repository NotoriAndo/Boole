# Rust tuple-struct checker qualification fixture

This is a public, synthetic and permanently non-issuable fixture for the
tracked `RUST-TUPLE-STRUCT-CHECKER-V1` release. It proves that a clean checkout
can execute the real semantic checker without a private experiment archive.

`accepted.rs` is intentionally public because this fixture can never be issued
as mining work. The other Rust files are negative controls, including direct
and scanner-confusion attempts to read the hidden harness. No real mining
answer, author witness or model transcript is stored here.

The fixture is Apache-2.0, like the Boole repository.
